# Plantillas Comprimidas para Tareas Frecuentes

## PLANTILLA: Continuar sesión anterior
```
[MEMORIA ANTERIOR]
=== MEMORIA SESIÓN... ===
[pegar bloque]

TAREA ACTUAL: [descripción en 1-2 oraciones]
```

## PLANTILLA: Análisis de código
```
CONTEXTO: [lenguaje, framework, objetivo]
PROBLEMA: [descripción específica]
CÓDIGO:
[solo la parte relevante, no el archivo entero]
RESULTADO ESPERADO: [qué debería hacer]
```

## PLANTILLA: Escritura/contenido
```
TIPO: [email/post/informe/etc]
AUDIENCIA: [a quién va]
TONO: [formal/casual/técnico]
PUNTOS CLAVE: [lista de 3-5 ideas]
LONGITUD: [aprox palabras o "corto/medio/largo"]
EVITAR: [restricciones si hay]
```

## PLANTILLA: Investigación
```
TEMA: [tema específico]
YA SÉ: [lo que ya conoce, para no repetir]
NECESITO: [qué tipo de info falta]
FORMATO: [bullets/tabla/prosa]
PROFUNDIDAD: [superficial/media/profunda]
```

## PLANTILLA: Iteración sobre trabajo previo
```
VERSIÓN ANTERIOR: [pegar solo lo que cambia]
CAMBIOS PEDIDOS:
  - [cambio 1]
  - [cambio 2]
MANTENER: [qué no debe cambiar]
```

## PLANTILLA: Tarea técnica larga (chunking)
```
PROYECTO: [nombre]
PASO ACTUAL: [N de M]
COMPLETADO: [resumen de pasos anteriores en 2 líneas]
TAREA: [solo el paso actual]
CONTEXTO MÍNIMO: [solo lo necesario para este paso]
```
